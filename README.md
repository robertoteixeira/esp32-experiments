# ESP32 Experiments

A collection of small ESP32 experiments created while learning embedded
development with PlatformIO and the Arduino framework.

## Hardware

- ESP32 DevKit V1
- Breadboard
- LEDs
- 220 ohm resistors
- Push buttons
- HC-SR501 PIR motion sensor
- Jumper wires
- Multimeter

## Development environment

- Ubuntu
- Visual Studio Code
- PlatformIO
- Arduino framework
- Board: ESP32 Dev Module (`esp32dev`)

## Experiments

Experiments are being reconstructed and added chronologically, with one Git
commit per completed experiment.
